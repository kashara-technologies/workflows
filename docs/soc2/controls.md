# SOC2 Control Catalog

> Framework: AICPA Trust Services Criteria 2017 (rev. 2022)
> Last updated: 2026-05-25
> Source of truth for the Kashara SOC2 monitoring dashboard.

## How to use this file

Each control is a level-2 heading. The YAML block immediately under the heading is parsed by the dashboard. The prose below the YAML is the AICPA definition. The Implementation notes section is free-text for what we have in place.

**Fields:**

| Field | Allowed values |
|---|---|
| `status` | `not_started` `in_progress` `implemented` `not_applicable` |
| `type_i_scope` | `in_scope` `out_of_scope` |
| `owner` | free text |
| `evidence_url` | URL to evidence (Drive, Notion, screenshot, policy doc) |
| `last_reviewed` | YYYY-MM-DD |

Edit this file directly. The dashboard parses on each request.
